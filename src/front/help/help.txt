usage: git dupe help [COMMAND]

Without COMMAND, prints the general help of git-dupe: what it answers
and the Git versions it supports. "git dupe -h" prints the same.

"git dupe help help" prints this text, and so does "git dupe help" with
-h or --help among its words.

With one of the ten commands git-dupe adds or changes, it prints that
command's text; with any other COMMAND, it runs "git help COMMAND", which
shows Git's own documentation of COMMAND, and ends with Git's exit status.

It takes no option, needs no repository, and needs nothing installed
beyond the git-dupe executable for the texts it prints itself.

The manual page of git-dupe, where it is installed, holds these texts and
more: a quick start, examples of daily use, and what one screen has no room
for, such as hidden and private paths, a file the project ignores, what plain
git does to private files, and the refused commands in full. "man git-dupe"
shows it, and so does "git dupe --help" while Git's help format is man, its
default.
