git-dupe

A second Git repo inside .git for the files that are yours, not the project's.

$ git status --short
?? AGENTS.md
?? notes/

$ git dupe init
Initialized empty Git repository in /home/brian/code/project/.git/dupe/
$ git dupe add notes/ AGENTS.md
hint: notes is now hidden from the project's Git; run from the root, 'git dupe unhide -- notes' stops hiding it
$ git dupe commit -m "Notes and agent instructions"
[main (root-commit) 3eb3af9] Notes and agent instructions
 3 files changed, 3 insertions(+)
 create mode 100644 .gitdupe
 create mode 100644 AGENTS.md
 create mode 100644 notes/todo.md

$ git status --short              # the project: nothing
$ git dupe log --oneline          # your files
3eb3af9 Notes and agent instructions
